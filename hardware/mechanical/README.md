# Mechanical Overview

Target enclosure language:

- CNC-machined aluminum primary shell
- smoked or transparent polycarbonate window over the display / indicator area
- deliberately larger than commodity USB-C dongles for passive thermal headroom

Nominal envelope:

- `95 mm x 42 mm x 18 mm`

Key mechanical constraints:

- RJ45 insertion force and cable retention
- captive USB-C cable strain relief
- thermal interface from hot components into shell
- button accessibility without weak cosmetic apertures
- OLED visibility through tinted window

See [`FUSION_NOTES.md`](FUSION_NOTES.md) for CAD handoff guidance.
